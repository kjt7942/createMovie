자동 설치

빠진 도구만 설치합니다. 새 콘솔 창이 열리고, 관리자 확인 창이 뜨면 '예'를 눌러 주세요.

처음 설치하는 방법

  1. Windows 10/11에서 이 폴더의 setup.bat을 더블클릭합니다.
  2. Python, Node.js, FFmpeg, Git이 없으면 winget으로 설치하고, 패키지와 글꼴을 받습니다.
  3. Gemini API 키를 묻습니다. Google AI Studio에서 무료로 발급받아 붙여 넣으세요. 나중에 .env에 넣어도 됩니다.
  4. NVIDIA GPU가 있으면 AI 영상 생성 도구를 설치할지 묻습니다.
  5. 바탕화면의 createMovie 바로가기나 start.bat으로 실행합니다. 주소는 http://localhost:5000입니다.

AI 영상 생성에 필요한 것

  1. NVIDIA GPU, GPU 메모리 8GB 이상. RTX 3070 Ti 8GB에서 시험했습니다.
  2. 디스크 여유 약 60GB. 내려받는 데 네트워크 속도에 따라 몇 시간이 걸릴 수 있습니다.
  3. GPU가 없으면 AI 영상 생성은 쓸 수 없지만 사진 홍보 영상은 그대로 쓸 수 있습니다.

직접 설치할 때

  1. winget install -e --id Python.Python.3.12
  2. winget install -e --id OpenJS.NodeJS.LTS
  3. winget install -e --id Gyan.FFmpeg
  4. winget install -e --id Git.Git
  5. pip install -r requirements.txt
  6. python tools/get_fonts.py
  7. npx -y hyperframes browser ensure
  8. .env 파일에 GEMINI_API_KEY=발급받은키
  9. AI 영상 생성: python tools/setup_h3.py

NAS에서는 Docker로 실행합니다. 렌더링은 PC 워커가 맡고, AI 영상 생성은 쓸 수 없습니다. 자세한 내용은 README를 보세요.
